**Component state:**
```typescript
const [sessionId, setSessionId] = useState<string | null>(null);

```

**Session lifecycle methods:**

1. `handleStart()` - Start new session
   - Generate seed: `Math.random().toString(36)`
   - Call POST /api/session/start with { seed, mode: 'TRAINING', packId: 'preflop-default', filters: { street: 'PREFLOP' } }
   - Set sessionId, currentSpot from response
   - Reset handCount and accuracy

2. `handleSubmitAction(actionId: ActionId)` - Submit user's decision
   - Lock buttons: `setUiState('submitted')`
   - Call POST /api/session/submit with { seed, sessionId, spot: currentSpot, actionId }
   - Wait 500ms (reveal delay from CONTEXT.md)
   - Set grade from response
   - Set `setUiState('revealed')`
   - Update accuracy calculation
   - For guests: call `incrementGuestHandCount()`
   - Check `isGuestLimitExceeded()` after increment

3. `handleNext()` - Advance to next hand
   - Reset state: `setUiState('idle')`, `setGrade(null)`
   - Call POST /api/session/next with { seed, sessionId }
   - Set currentSpot from response
   - Increment handCount

4. `handleStop()` - End session
   - Show summary screen (hands, accuracy, EV loss)
   - For guests: check limit and show sign-up prompt if exceeded

**Keyboard shortcuts:**
- Space/Enter: Call handleNext() if uiState === 'revealed'
- 1/F: Fold action
- 2/C: Call action
- 3/R: Raise action

**Render structure:**
