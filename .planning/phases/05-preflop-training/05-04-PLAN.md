**Full Training Flow Verification:**

1. **Start Session:**
   - Navigate to `http://localhost:3000/preflop-training`
   - Click "Start Training" button
   - Verify: First preflop spot loads with hero cards displayed
   - Verify: Hand counter shows "Hand #1"

2. **RFI Scenario (First to Act):**
   - Wait for spot with no prior action (empty action history)
   - Verify: Action history text shows "First to act"
   - Verify: Available actions are Fold, Raise (no Call option)
   - Submit Raise action
   - Verify: 500ms delay before feedback appears
   - Verify: All buttons show EV and frequency after reveal
   - Verify: Frequency bars display with percentages
   - Verify: Color coding correct (green for high %, yellow/red for lower)
   - Verify: Your chosen action has blue border ring

3. **Facing Open Scenario:**
   - Click Next or press Space
   - Wait for spot with history.length === 1 (one prior action)
   - Verify: Action history shows format like "RAISE 2.5BB"
   - Verify: Available actions include Fold, Call, Raise
   - Submit any action
   - Verify: Feedback displays correctly with EV and frequencies

4. **3Bet Scenario:**
   - Continue clicking Next until spot with history.length === 2
   - Verify: Action history shows "RAISE 2.5BB → RAISE 7.5BB"
   - Verify: Available actions displayed
   - Submit action and verify feedback

5. **Blind Defense Scenario:**
   - Continue until hero is SB or BB with prior action
   - Verify: Action history displays appropriately
   - Submit action and verify feedback

6. **Keyboard Shortcuts:**
   - Test F (Fold), C (Call), R (Raise) keys
   - Test 1 (Fold), 2 (Call), 3 (Raise) keys
   - Test Space and Enter for Next
   - Verify: All shortcuts work correctly

7. **Accuracy Tracking:**
   - Play 10 hands
   - Verify: Hand counter increments to "Hand #10"
   - Verify: Accuracy percentage updates after each decision
   - Check that accuracy formula makes sense (100% if all optimal, lower if mistakes)

8. **Guest Limiting:**
   - Open browser DevTools → Application → localStorage
   - Find key `guest_training_hands`
   - Manually set value to: `{"date":"[today's date string]","count":49}`
   - Refresh page, start new session
   - Play one hand
   - Verify: After submitting action, modal appears: "50 hand limit reached. Sign up for unlimited training!"
   - Verify: Counter in localStorage incremented to 50

9. **Day Boundary Reset:**
   - Set localStorage to: `{"date":"Sat Feb 15 2026","count":50}` (yesterday's date)
   - Refresh page, start session
   - Play one hand
   - Verify: No limit modal appears (counter reset for new day)
   - Check localStorage - should show today's date with count: 1

10. **Visual Quality:**
    - Verify: Frequency bars animate smoothly
    - Verify: Color transitions are clear (green vs yellow vs red distinguishable)
    - Verify: Text is readable (action history, EV values, percentages)
    - Verify: Layout doesn't break on smaller viewports (1280x720 minimum)
