
**Classification function:**
```typescript
export function classifyPreflopScenario(spot: Spot): PreflopScenarioType | null
```

Classification rules (from RESEARCH.md Pattern 1):
- Return `null` if spot.street !== 'PREFLOP' (not a preflop spot)
- RFI: `history.length === 0` (first to act)
- FacingOpen: `history.length === 1` (single open raise before hero)
- 3Bet: `history.length === 2` (open + 3bet before hero)
- BlindDefense: `(heroToAct === 'SB' || heroToAct === 'BB') && history.length >= 1` (blinds facing action)

**Important:** If multiple conditions match (e.g., BB facing open is both FacingOpen and BlindDefense), prioritize BlindDefense (most specific scenario type).

- Test non-preflop spots return null
- Test edge cases (empty history, SB vs BB)
