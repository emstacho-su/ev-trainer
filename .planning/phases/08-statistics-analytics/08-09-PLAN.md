Create a new "use client" component `SessionReplay` that renders a hand-by-hand review interface.

**Props:**
```typescript
interface SessionReplayProps {
  entries: SessionEntryDetail[];
  onClose: () => void;
}
```

**State:**
- `currentIndex: number` (starts at 0)

**Layout (simplified review card, NOT the full PokerTable):**
Each "card" shows one hand's review info in a compact dark card format (bg-slate-800 rounded-lg border border-slate-700 p-6):

Top line: "Hand {index + 1} of {entries.length}" in text-sm text-slate-400
Below that, a grid (grid-cols-2 gap-4 on md, single col on mobile) showing:
- **Spot**: entry.spotId (first 12 chars) in text-slate-200 font-mono
- **Your Action**: entry.actionId in a colored badge (green-500/20 + text-green-400 if correct, red-500/20 + text-red-400 if incorrect)
- **Result**: entry.result.grade in the same color coding
- **EV Difference**: formatted as `{Math.abs(evDiff).toFixed(3)} BB` with a minus sign prefix if loss, dash if zero

If entry.result.allActions exists and has items, show an "Optimal Strategy" section below the grid:
- List top 3 actions sorted by EV descending
- Each shows: `{actionId} ({(frequency * 100).toFixed(0)}%) — {ev.toFixed(3)} BB`
- Use text-sm text-slate-400

**Navigation bar** (below the card, flex justify-between items-center):
- Left: "Prev" button (disabled when currentIndex === 0), styled as bg-slate-700 text-slate-200 rounded px-4 py-2 text-sm
- Center: Dot indicators or "{current + 1} / {total}" text counter
- Right: "Next" button (disabled when currentIndex === entries.length - 1), same styling
- Far right: "Exit Replay" button (text-slate-400 hover:text-slate-200 text-sm underline), calls onClose

**Keyboard navigation:** Add useEffect with keydown handler:
- ArrowLeft or 'p': go to prev (if not at 0)
- ArrowRight or 'n': go to next (if not at end)
- Escape: call onClose

Grade/correct detection logic (same as SessionHistory):
- grade = entry.result?.grade ?? "PENDING"
- isCorrect = grade === "CORRECT" || grade === "OPTIMAL"

Import SessionEntryDetail from "@/lib/stats/types" (or relative path "../../../lib/stats/types").
