  <behavior>
    classifyBoardTexture(board: Card[]): BoardTexture

    Priority order (important — determines which category wins on overlap):
    1. PAIRED — 2 cards share the same rank (e.g. AsAh2d)
    2. MONOTONE — 3 cards share the same suit (e.g. AhKhQh)
    3. TWO_TONE — exactly 2 cards share the same suit (e.g. AhKh2d)
    4. CONNECTED — no pair, not monotone/two-tone, maxGap between sorted ranks <= 3 (e.g. 9h8d7c)
    5. RAINBOW — default (e.g. AhKdQc)

    Test cases:
    - ['As','Ah','2d'] -> 'PAIRED'           (pair + two-tone, pair wins)
    - ['Ah','Kh','Qh'] -> 'MONOTONE'
    - ['Ah','Kh','2d'] -> 'TWO_TONE'
    - ['9h','8d','7c'] -> 'CONNECTED'        (maxGap = 1)
    - ['Ah','Kd','Qc'] -> 'RAINBOW'
    - ['As','Ad','Ah'] -> 'PAIRED'           (trips board - PAIRED wins over MONOTONE)
    - ['Ts','9d','8h'] -> 'CONNECTED'
    - ['Ah','2d','9c'] -> 'RAINBOW'          (maxGap = 11, not connected)

    Ranks: A=14, K=13, Q=12, J=11, T=10, 9=9, ... 2=2
    Card format: 'As' (rank char + suit char), same as engine Card type
  </behavior>
  <implementation>
    Types file (src/lib/postflop/types.ts):
    - Export Street = 'FLOP' | 'TURN' | 'RIVER'
    - Export BoardTexture = 'MONOTONE' | 'PAIRED' | 'TWO_TONE' | 'CONNECTED' | 'RAINBOW'
    - Export StreetDecisionState = 'deciding' | 'evaluating' | 'advancing' | 'complete'
    - Export PostflopSpot: { heroHand: [Card, Card]; board: Card[]; potBb: number; stackBb: number; heroPosition: 'IP' | 'OOP'; villainPosition: 'IP' | 'OOP'; preflopHistory: string }
    - Export StreetDecision: { actionId: string; solverOutput: SolverNodeOutput | null; isOnSolverLine: boolean }
    - Export HandSummaryData: { spot: PostflopSpot; decisions: Partial<Record<Street, StreetDecision>>; deviatedStreet: Street | null; completedAt: string }
    - Export PostflopMachineState = 'deciding' | 'evaluating' | 'advancing' | 'summary' | 'idle'

    boardTexture.ts:
    - Parse rank from card string: 'A'=14, 'K'=13, 'Q'=12, 'J'=11, 'T'=10, '2'-'9' as integer
    - Parse suit from card string: second character ('s','h','d','c')
    - Check PAIRED first (rankCounts has any value >= 2)
    - Check MONOTONE (suitCounts has any value >= 3)
    - Check TWO_TONE (suitCounts has any value >= 2)
    - Check CONNECTED (sort ranks, compute gaps between adjacent, maxGap <= 3)
    - Default RAINBOW
    - Throw if board.length < 3

    Use existing Card type from src/lib/engine/types.ts (type Card = string template literal).
  </implementation>
