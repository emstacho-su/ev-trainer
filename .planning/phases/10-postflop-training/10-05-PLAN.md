    startNewHand():
      - Generate new spot: generatePostflopHand()
      - dispatch({ type: 'START_HAND', payload: spot })

    handleUserDecision(actionId: string):
      - dispatch({ type: 'USER_DECIDED', payload: { actionId } })
      - Set isLoading = true
      - Call fetchPostflopSolution(config built from current state)
      - On success: dispatch({ type: 'SOLVER_OUTPUT', payload: { output } })
      - Set isLoading = false
      - After 500ms delay: sample villain action with sampleVillainAction(output)
      - Show villain action label for 1000ms (via villainActionLabel state)
      - After villain delay: dispatch({ type: 'ADVANCE_STREET', payload: { nextBoard } })
        where nextBoard = current board + next card (turn: board[3], river: board[4])
        Advance from full 5-card board generated at start

    villainActionLabel: managed as local useState string | null

    Create src/components/poker/organisms/PostflopTrainingSession.tsx:
    - 'use client'
    - Wraps content with PostflopSessionProvider (from postflopSession.ts)
    - Inner component PostflopTrainingSessionInner uses usePostflopTraining()
    - Uses usePostflopSession() for state
    - Layout: reuse PokerTable organism for table display
      - board: state.board (community cards)
      - players: heroHand cards visible, villain cards face-down
      - pot: state.potBb
    - Below table: SpotContextLabel (derive potType from preflopHistory, heroPosition, heroRole from IP/OOP + aggressor/caller)
    - Below context: StreetActionPanel
      - If machineState='deciding' and isLoading=false: pass current solver actions (empty [] triggers loading spinner)
      - If machineState='evaluating' or 'advancing': pass actions with isRevealed=true
      - selectedActionId: from decisions[currentStreet]?.actionId
