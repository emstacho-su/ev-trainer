Create `src/lib/range/types.ts` with TypeScript interfaces:
- `ActionType = 'fold' | 'call' | 'raise' | 'jam'`
- `HandAction = { hand: string; actions: Array<{ type: ActionType; frequency: number }> }`
- `RangeData = { hands: HandAction[]; totalCombos: number }`
- `EquityCategory = 'premium-pairs' | 'medium-pairs' | 'small-pairs' | 'broadway' | 'suited-connectors' | 'suited-gappers' | 'offsuit'`

Create `src/lib/range/rangeHelpers.ts` with utility functions:
- `normalizeHandString(hand: string): string` - Converts hand to canonical form (AKs, AKo, AA)
- `categorizeHandStrength(hand: string): EquityCategory` - Maps hand to equity category
- `normalizeActionFrequencies(actions: Array<{type: ActionType; frequency: number}>): Array<{type: ActionType; frequency: number}>` - Ensures frequencies sum to 1.0 (handles floating-point rounding)

Create `src/lib/range/colorScheme.ts`:
- `ACTION_COLORS` constant mapping ActionType to CSS variable names
- `getActionColor(action: ActionType): string` - Returns CSS variable reference

Create `src/lib/range/gridLayout.ts` (CRITICAL - replaces unmaintained @holdem-poker-tools/hand-matrix):
- `RANKS` array: ['A', 'K', 'Q', 'J', 'T', '9', '8', '7', '6', '5', '4', '3', '2']
- `RANK_INDEX` record for fast lookup
- `getGridPosition(hand: string): [number, number] | null` - Maps hand to grid position (pairs on diagonal, suited above, offsuit below)
  - Example: AA -> [0,0], AKs -> [0,1], AKo -> [1,0]
- `getHandAtPosition(row: number, col: number): string | null` - Inverse mapping from position to hand

Follow RESEARCH.md Pattern 2 for gridLayout implementation (~50 lines, deterministic mapping).

Create `src/lib/range/index.ts` as barrel export.
