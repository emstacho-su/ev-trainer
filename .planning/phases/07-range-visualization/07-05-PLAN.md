  <what-built>
Range visualization modal with:
- Side-by-side 13x13 hero/villain range grids
- Stacked action bars in cells (GTO Nexus style)
- Clickable action legend filters
- Tabbed equity breakdown (Hand Strength / Action Groups)
- Board cards display between grids

  </what-built>
  <how-to-verify>
**1. Start Training Session**
- Run `npm run dev` and navigate to training page
- Start a preflop training session
- Submit a decision to reveal solver output
- Click "View Ranges" button

**2. Visual Design Verification**
- [ ] Modal opens with dark theme background (hsl(var(--background)))
- [ ] Hero range grid on left, Villain range on right
- [ ] 13x13 grid layout with hands in correct positions (AA top-left, pairs on diagonal, suited above, offsuit below)
- [ ] Board cards or "Preflop" text displayed between grids
- [ ] Cell stacked bars show action frequencies with correct colors:
  - Green for call/check
  - Red for raise
  - Dark gray for fold
  - Pure red (#ff0000) for jam/all-in
- [ ] Current training hand highlighted with blue border and glow
- [ ] Hand labels (e.g., "AKs") readable on stacked bar backgrounds

**3. Action Legend Filtering**
- [ ] Action legend below each grid shows frequency percentages (e.g., "Fold 78.1%, Call 21.9%")
- [ ] Click "Fold" button → non-fold cells dim (opacity-30), fold cells stay visible
- [ ] Click "Fold" again → filter clears, all cells return to normal opacity
- [ ] Click "Call" → only call cells visible
- [ ] Click "Raise" → only raise cells visible
- [ ] Selected action button shows blue ring (ring-2 ring-blue-400)

**4. Equity Breakdown Tabs**
- [ ] Equity breakdown section displays below grids
- [ ] "Hand Strength" tab active by default
- [ ] Categories display for both hero and villain:
  - Premium pairs (AA-QQ)
  - Medium pairs (JJ-77)
  - Small pairs (66-22)
  - Broadway, Suited connectors, Suited gappers, Offsuit
- [ ] Percentages sum to ~100% for each player
- [ ] Click "Action Groups" tab → categories change to:
  - Pure raise, Mixed raise/call, Pure call, Pure fold
- [ ] Click a category row → corresponding hands highlight in grid
- [ ] Selected category row shows blue background

**5. Responsive Behavior**
- [ ] Desktop (1024px+): Hero/Villain grids side-by-side, equity breakdown below
- [ ] Tablet (768px): Grids stack vertically, equity breakdown below
- [ ] Mobile (375px): All components stack vertically, cells smaller (w-10 h-10)
- [ ] Modal fits viewport at all breakpoints (no horizontal scroll)

**6. Accessibility**
- [ ] Press ESC → modal closes, focus returns to "View Ranges" button
- [ ] Click overlay outside modal → modal closes
- [ ] Tab key cycles focus within modal only (focus trapped)
- [ ] Close button (X) in top-right corner works
- [ ] Screen reader announces modal title "Range Visualization" on open

**7. Interaction Edge Cases**
- [ ] Reopen modal → filters reset to null (no previous selection persists)
- [ ] Apply both action filter AND equity category filter simultaneously → correct intersection highlights
- [ ] Hover over cell → tooltip shows action breakdown (if implemented)
- [ ] Empty range data (no hands) → grid shows all gray cells

**Expected Outcome:**
All checkboxes above should be checked. If any fail, describe the issue in detail for fix planning.
