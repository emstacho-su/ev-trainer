Grid rendering logic (CRITICAL - replaces hand-matrix library):
```typescript
// Generate all 169 grid positions
const gridCells = [];
for (let row = 0; row < 13; row++) {
  for (let col = 0; col < 13; col++) {
    const hand = getHandAtPosition(row, col);
    if (!hand) continue;

    const handAction = range.hands.find(h => h.hand === hand);
    const actions = handAction?.actions || [];

    gridCells.push(
      <RangeGridCell
        key={hand}
        hand={hand}
        actions={actions}
        isCurrentHand={hand === currentHand}
      />
    );
  }
}
```

Responsive sizing:
- Cell size: `w-12 h-12 md:w-14 md:h-14` for mobile/desktop
- Grid gap: `gap-0.5` for tight poker grid aesthetic
- Container max width to prevent excessive stretching
