Implement Express app following research Pattern 5 (Health Check) and Pattern 4 (Error Handling).

**src/server/middleware/error.middleware.ts:**
1. Define AppError class extending Error with statusCode, message, code fields
2. Implement errorHandler middleware function:
   - Check if error is AppError instance, return appropriate status + JSON
   - For unexpected errors, log to console and return 500
   - In production, hide error details; in dev, show full message
3. Export both AppError class and errorHandler function

**src/server/middleware/validate.middleware.ts:**
1. Import Zod types
2. Implement validate(schema: ZodSchema) middleware factory
3. On validation error, return 400 with { error: { code: 'VALIDATION_ERROR', message, details } }
4. On success, call next()
5. Export validate function

**src/server/routes/health.routes.ts:**
1. Create Router instance
2. Define GET /health endpoint:
   - Try `await prisma.$queryRaw\`SELECT 1\``
   - On success: return 200 with { status: 'ok', timestamp }
   - On error: return 503 with { status: 'error', message: 'Database unavailable' }
3. Define GET /ready endpoint (always returns 200 with { status: 'ready' })
4. Export router as default

**src/server/app.ts:**
1. Import express, helmet, cors, compression, express-rate-limit, express-async-errors
2. Import errorHandler from error.middleware
3. Import healthRoutes
4. Create app = express()
5. Apply middleware in order:

   - compression() (gzip)
   - express.json({ limit: '1mb' })
6. Mount routes:
   - app.use('/health', healthRoutes)
   - (session routes mounted in Task 3)
7. Register error handler LAST: app.use(errorHandler)
8. Export app as default

   - Call handleStart(req.body)
   - Return res.status(result.status).json(result.body)
   - Wrap in try/catch, call next(error) on failure
4. Implement nextDecision async function (same pattern with handleNext)
5. Implement submitDecision async function (same pattern with handleSubmit)
6. Implement getSession async function (same pattern with handleGetSession)
7. Export all four functions

**src/server/routes/session.routes.ts:**
1. Import Router from express
2. Import validate from middleware/validate.middleware
3. Import controllers (startSession, nextDecision, submitDecision, getSession)
4. Define Zod schemas for each endpoint:
   - startSessionSchema: { seed: string, mode: enum(['TRAINING', 'PRACTICE']), packId?: string, filters?: object }
   - nextSessionSchema: { sessionId: string, seed: string }
   - submitSessionSchema: { sessionId: string, seed: string, actionId: string }
   - getSessionSchema: { sessionId: string, seed: string }
5. Create router and define routes:
   - POST /start with validate(startSessionSchema), startSession
   - POST /next with validate(nextSessionSchema), nextDecision
   - POST /submit with validate(submitSessionSchema), submitDecision
   - GET /:sessionId (pass seed as query param) with getSession
6. Export router as default
