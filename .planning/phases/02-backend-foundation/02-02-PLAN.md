**BREAKING CHANGE: Convert SessionStoreBackend to async pattern for Prisma compatibility**

**src/lib/v2/sessionStore.ts:**
1. Update SessionStoreBackend interface:
   - `get(key: string): Promise<SessionRecord | undefined>` (was sync)
   - `set(key: string, value: SessionRecord): Promise<void>` (was sync)
   - `clear(): Promise<void>` (was sync)
2. Update InMemorySessionStoreBackend implementation to async:
   - Each method returns Promise.resolve() wrapping existing logic
   - No actual async operations, just async signature for compatibility
3. Update all exported functions to async:
   - `async function createSessionRecord(...)` - await backend.get, await backend.set
   - `async function getSessionRecord(...)` - await backend.get
   - `async function updateSessionSpot(...)` - await getSessionRecord, no backend call needed (in-memory mutation)
   - `async function appendSessionEntry(...)` - await getSessionRecord, no backend call needed (in-memory mutation)
   - `async function clearSessionStore()` - await backend.clear
4. Change return types:
   - createSessionRecord: Promise<SessionRecord>
   - getSessionRecord: Promise<SessionRecord | null>
   - updateSessionSpot: Promise<SessionRecord>
   - appendSessionEntry: Promise<SessionRecord>
   - clearSessionStore: Promise<void>

**src/lib/v2/api/sessionHandlers.ts:**
1. Update all handler functions to async:
   - `export async function handleStart(input: unknown): Promise<ApiResult<StartResponse>>`
   - `export async function handleNext(input: unknown): Promise<ApiResult<NextResponse>>`
   - `export async function handleSubmit(input: unknown): Promise<ApiResult<SubmitTrainingResponse | SubmitPracticeResponse>>`
   - `export async function handleGetSession(sessionId: string, seed?: string | null): Promise<ApiResult<SessionDetailResponse>>`
2. Add `await` to all sessionStore function calls:
   - `const record = await createSessionRecord(...)`
   - `const record = await getSessionRecord(...)`
   - `await updateSessionSpot(...)`
   - `await appendSessionEntry(...)`
3. Preserve ALL business logic - only add async/await, no other changes
