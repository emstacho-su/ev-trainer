  <name>Task 2: Implement async PrismaSessionStoreBackend</name>
  <files>src/lib/v2/storage/prismaSessionStore.ts</files>
  <action>
Implement Prisma-backed SessionStoreBackend following research Pattern 3 (Prisma-Backed SessionStore Implementation).

**src/lib/v2/storage/prismaSessionStore.ts:**

1. Import SessionStoreBackend, SessionRecord, SessionEntry types from ../sessionStore
2. Import prisma from ../../lib/prisma/client
3. Import Prisma types (@prisma/client)

4. Define PrismaSessionStoreBackend class implementing SessionStoreBackend:

**async get(key: string): Promise<SessionRecord | undefined>**
- Query: `await prisma.session.findUnique({ where: { runtimeKey: key }, include: { entries: true } })`
- If not found, return undefined
- Map Prisma model to SessionRecord interface:
  - Parse filters field from JSON to SpotFilterInput
  - Parse currentSpot field from JSON to Spot | null
  - Map entries array from Prisma SessionEntry[] to SessionEntry[]
    - Parse spot field from JSON to Spot
    - Parse result field from JSON to DecisionGrade | undefined
- Return mapped SessionRecord

**async set(key: string, value: SessionRecord): Promise<void>**
- Use upsert pattern: `await prisma.session.upsert({ where: { runtimeKey: key }, create: {...}, update: {...} })`
- Create block: All fields from SessionRecord
  - runtimeKey: key
  - sessionId, seed, mode, packId, filters (as JSON), decisionIndex, decisionsPerSession, currentSpot (as JSON), isComplete: false
- Update block: decisionIndex, currentSpot (as JSON)
- Handle entries separately:
  - Delete existing entries: `await prisma.sessionEntry.deleteMany({ where: { sessionId: session.id } })`
  - Create new entries: `await prisma.sessionEntry.createMany({ data: value.entries.map(...) })`
  - Map entries to include spot (as JSON), result (as JSON)
- Wrap in transaction: `await prisma.$transaction([...])`

**async clear(): Promise<void>**
- Delete all sessions: `await prisma.session.deleteMany()`
- Cascade deletes entries automatically

**DO NOT implement delete() method** - it is not in the SessionStoreBackend interface.

5. Export PrismaSessionStoreBackend class

**Critical preservation:**
- Deterministic properties preserved: same seed + sessionId MUST produce same runtimeKey and retrieve same session
- JSON serialization must handle Spot and DecisionGrade structures correctly
