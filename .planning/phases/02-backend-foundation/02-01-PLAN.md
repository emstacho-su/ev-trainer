<task type="auto">
  <name>Task 2: Define Prisma schema with session models and verify JSON compatibility</name>
  <files>prisma/schema.prisma, .env.example, docker-compose.yml</files>
  <action>
Create PostgreSQL schema following the research Pattern 3 (Prisma Schema for Session Data).

Models to define:

**User:**
- id: String @id @default(cuid())
- email: String @unique
- passwordHash: String? (nullable for OAuth users)
- oauthProvider: String?
- oauthProviderId: String?
- subscriptionTier: String @default("FREE")
- createdAt: DateTime @default(now())
- updatedAt: DateTime @updatedAt
- Relations: sessions, dailyStats, spotStats
- Indexes: @@index([email]), @@unique([oauthProvider, oauthProviderId])

**Session:**
- id: String @id @default(cuid())
- runtimeKey: String @unique (for deterministic lookup: hash(seed, sessionId))
- sessionId: String
- seed: String
- userId: String? (nullable for guest sessions)
- mode: String (TRAINING | PRACTICE)
- packId: String
- filters: Json (SpotFilterInput)
- decisionIndex: Int @default(0)
- decisionsPerSession: Int @default(10)
- currentSpot: Json? (Spot interface, nullable)
- isComplete: Boolean @default(false)
- createdAt: DateTime @default(now())
- updatedAt: DateTime @updatedAt
- Relations: user, entries
- Indexes: @@index([userId, createdAt]), @@index([sessionId, seed]), @@unique([sessionId, seed])

**SessionEntry:**
- id: String @id @default(cuid())
- sessionId: String (foreign key to Session.id)
- index: Int
- spotId: String
- spot: Json (Full Spot data)
- actionId: String
- result: Json? (DecisionGrade, nullable)
- createdAt: DateTime @default(now())
- Relation: session (onDelete: Cascade)
- Indexes: @@index([sessionId, index]), @@unique([sessionId, index])

**SpotStat:**
- id: String @id @default(cuid())
- userId: String
- spotId: String
- street: String
- heroPosition: String
- villainPosition: String?
- totalDecisions: Int @default(0)
- correctDecisions: Int @default(0)
- avgEvLoss: Decimal @db.Decimal(10, 4)
- lastPracticed: DateTime
- updatedAt: DateTime @updatedAt
- Relation: user
- Indexes: @@index([userId, spotId]), @@unique([userId, spotId])

**DailyStat:**
- id: String @id @default(cuid())
- userId: String
- date: DateTime @db.Date
- totalDecisions: Int @default(0)
- correctDecisions: Int @default(0)
- avgEvLoss: Decimal @db.Decimal(10, 4)
- sessionsCompleted: Int @default(0)
- Relation: user
- Indexes: @@index([userId, date]), @@unique([userId, date])

Set datasource provider to "postgresql" with url from env("DATABASE_URL").
Set generator to "prisma-client-js".

    ports:
      - "5432:5432"

      - postgres-data:/var/lib/postgresql/data

  postgres-data:

Create .env file from .env.example with local Docker connection:

Implement singleton PrismaClient following research Pattern 1 (Prisma Client Singleton).

Create src/lib/prisma/client.ts with:

1. Import PrismaClient, PrismaPg adapter, and pg Pool
2. Read DATABASE_URL from process.env (use dotenv if needed for local dev)
3. Create pg.Pool with configuration:
   - connectionString from DATABASE_URL
   - max: 20 (connection pool size)
   - idleTimeoutMillis: 30000
   - connectionTimeoutMillis: 2000
   - maxLifetimeSeconds: 60
4. Create PrismaPg adapter from pool
5. Implement singleton pattern with globalThis caching:
   - Define prismaClientSingleton() function
   - Use globalThis.prismaGlobal in non-production
   - Export single prisma instance
6. Add pool error event listener for unexpected errors
7. Configure Prisma log levels based on NODE_ENV (query/error/warn in dev, error only in prod)

Export as default: `export default prisma;`

This ensures single PrismaClient instance throughout application lifecycle, preventing connection pool exhaustion.
