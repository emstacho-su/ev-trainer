<task type="auto">
  <name>Task 2: Define Prisma schema with session models</name>
  <files>prisma/schema.prisma, .env.example</files>
  <action>
Create PostgreSQL schema following the research Pattern 3 (Prisma Schema for Session Data).

Models to define:

**User:**
- id: String @id @default(cuid())
- email: String @unique
- passwordHash: String? (nullable for OAuth users)
- oauthProvider: String?
- oauthProviderId: String?
- subscriptionTier: String @default("FREE")
- createdAt: DateTime @default(now())
- updatedAt: DateTime @updatedAt
- Relations: sessions, dailyStats, spotStats
- Indexes: @@index([email]), @@unique([oauthProvider, oauthProviderId])

**Session:**
- id: String @id @default(cuid())
- runtimeKey: String @unique (for deterministic lookup: hash(seed, sessionId))
- sessionId: String
- seed: String
- userId: String? (nullable for guest sessions)
- mode: String (TRAINING | PRACTICE)
- packId: String
- filters: Json (SpotFilterInput)
- decisionIndex: Int @default(0)
- decisionsPerSession: Int @default(10)
- currentSpot: Json? (Spot interface, nullable)
- isComplete: Boolean @default(false)
- createdAt: DateTime @default(now())
- updatedAt: DateTime @updatedAt
- Relations: user, entries
- Indexes: @@index([userId, createdAt]), @@index([sessionId, seed]), @@unique([sessionId, seed])

**SessionEntry:**
- id: String @id @default(cuid())
- sessionId: String (foreign key to Session.id)
- index: Int
- spotId: String
- spot: Json (Full Spot data)
- actionId: String
- result: Json? (DecisionGrade, nullable)
- createdAt: DateTime @default(now())
- Relation: session (onDelete: Cascade)
- Indexes: @@index([sessionId, index]), @@unique([sessionId, index])

**SpotStat:**
- id: String @id @default(cuid())
- userId: String
- spotId: String
- street: String
- heroPosition: String
- villainPosition: String?
- totalDecisions: Int @default(0)
- correctDecisions: Int @default(0)
- avgEvLoss: Decimal @db.Decimal(10, 4)
- lastPracticed: DateTime
- updatedAt: DateTime @updatedAt
- Relation: user
- Indexes: @@index([userId, spotId]), @@unique([userId, spotId])

**DailyStat:**
- id: String @id @default(cuid())
- userId: String
- date: DateTime @db.Date
- totalDecisions: Int @default(0)
- correctDecisions: Int @default(0)
- avgEvLoss: Decimal @db.Decimal(10, 4)
- sessionsCompleted: Int @default(0)
- Relation: user
- Indexes: @@index([userId, date]), @@unique([userId, date])

Set datasource provider to "postgresql" with url from env("DATABASE_URL").
Set generator to "prisma-client-js".

Create .env.example with placeholder DATABASE_URL:
```
DATABASE_URL="postgresql://user:password@localhost:5432/ev_trainer?schema=public"
```

After schema complete, run `npx prisma generate` to generate Prisma Client types.
