  <files>

  <action>
    Create `src/lib/supabase/statsService.ts` with all stats query functions:

    1. `getDailyStats(supabase, params: { startDate?, endDate? })`:
       - Query daily_stats table with date range filters
       - Return: array of { date, total_decisions, correct_decisions, avg_ev_loss, sessions_completed }
       - Order by date ascending

    2. `getOverviewStats(supabase)`:
       - Query daily_stats for lifetime totals (SUM of decisions, correct, sessions)
       - Calculate overall accuracy, total EV loss
       - Query for last 7 days vs previous 7 days for trend
       - Return: { totalDecisions, accuracy, avgEvLoss, sessionsCompleted, trend }

    3. `getPositionStats(supabase, params: { startDate?, endDate? })`:
       - Query spot_stats grouped by hero_position
       - Return: array of { position, totalDecisions, correctDecisions, avgEvLoss }
       - For heatmap: return 2D data keyed by hero_position x villain_position

    4. `getWeaknessBreakdown(supabase, params: { limit? })`:
       - Query spot_stats ordered by avg_ev_loss descending
       - Filter: total_decisions >= 10 (confidence threshold)
       - Return: top N weakest spots with position, pot_type, avg_ev_loss

    5. `getSessionHistory(supabase, params: { page, pageSize, startDate?, endDate?, sortBy?, sortOrder? })`:
       - Query training_sessions with pagination
       - Join with entry count and accuracy calculation
       - Return: { sessions: [...], total, page, pageSize, hasMore }

    6. `getSessionDetail(supabase, sessionId, userId)`:
       - Query single training_session with all session_entries
       - Verify ownership via userId
       - Return session detail with entries and biggest mistakes, or null if not found

    7. `deleteSession(supabase, sessionId, userId)`:
       - Delete training_session WHERE id = sessionId AND user_id = userId
       - Return boolean (true if deleted, false if not found)

    8. `getFlaggedHands(supabase, params?: { startDate?, endDate?, positions?, scenarios?, streets? })`:
       - Query session_entries WHERE is_flagged = true
       - Join with training_session for context
       - Support optional filters (date range, positions, scenarios, streets)
       - Return: { entries: FlaggedEntry[] }

    9. `toggleEntryFlag(supabase, sessionId, entryIndex, userId)`:
       - Find session_entry by sessionId + entryIndex, verify session ownership
       - Toggle is_flagged boolean
       - Return: { isFlagged: boolean } or null if not found

    10. `getDrillSuggestions(supabase)`:
       - Query spot_stats WHERE total_decisions >= 10
       - Order by avg_ev_loss descending
       - Return: top 5 worst-performing spot categories

    11. `upsertDailyStats(supabase, userId, date, stats)`:
       - Upsert into daily_stats (increment on conflict)
       - Called after session completion to update daily aggregates

    12. `upsertSpotStats(supabase, userId, spotMeta, grade)`:
       - Upsert into spot_stats (update running averages on conflict)
       - Called after each decision submission

    All functions take Supabase client as first param. Use Supabase query builder (.select, .eq, .gte, .lte, .order, .limit, .range for pagination).

    For aggregation queries that Supabase client can't do efficiently (complex GROUP BY), use `supabase.rpc()` with a database function, OR do client-side aggregation on the returned rows. Prefer server-side when possible.
