  <action>
    Create `supabase/migrations/001_initial_schema.sql` with all tables. Use the schema from 11-RESEARCH.md as the base, with these specifics:

    **Tables to create (in order for FK resolution):**

    1. `profiles` -- Extends auth.users
       - id UUID PK references auth.users(id) ON DELETE CASCADE
       - display_name TEXT
       - subscription_tier TEXT NOT NULL DEFAULT 'FREE'
       - trainer_preferences JSONB (stores TrainerConfig)
       - created_at, updated_at TIMESTAMPTZ

    2. `spots` -- Practice spot library (replaces bundled JSON packs)
       - id UUID PK DEFAULT gen_random_uuid()
       - spot_id TEXT NOT NULL UNIQUE (deterministic spot identifier)
       - is_system BOOLEAN NOT NULL DEFAULT false
       - created_by UUID FK auth.users ON DELETE SET NULL
       - street, hero_position, villain_position, board TEXT[], hero_to_act, positions TEXT[]
       - stacks_bb JSONB, pot_bb NUMERIC(10,2), history TEXT[], hero_hand TEXT[]
       - pot_type, effective_stack_bb, scenario_type, difficulty_rating, tags TEXT[]
       - share_code TEXT UNIQUE (for shareable links)
       - GIN index on tags, indexes on street, hero_position, pot_type, is_system, created_by

    3. `training_sessions` -- Training/practice sessions
       - id UUID PK, user_id UUID FK auth.users ON DELETE CASCADE
       - session_id TEXT, seed TEXT, mode TEXT, filters JSONB
       - decision_index INT, decisions_per_session INT, current_spot JSONB
       - is_complete BOOLEAN, target_stack_bb NUMERIC
       - UNIQUE(session_id, seed), index on (user_id, created_at)

    4. `session_entries` -- Individual decisions within sessions
       - id UUID PK, session_id UUID FK training_sessions ON DELETE CASCADE
       - index INT, spot_id TEXT, spot JSONB, action_id TEXT, result JSONB
       - is_flagged BOOLEAN DEFAULT false
       - UNIQUE(session_id, index), indexes on (session_id, index) and (session_id, is_flagged)

    5. `daily_stats` -- Pre-aggregated daily performance
       - id UUID PK, user_id UUID FK, date DATE
       - total_decisions INT, correct_decisions INT, avg_ev_loss NUMERIC(10,4), sessions_completed INT
       - UNIQUE(user_id, date), index on (user_id, date)

    6. `spot_stats` -- Per-spot performance tracking
       - id UUID PK, user_id UUID FK, spot_id TEXT
       - street, hero_position, villain_position, total_decisions, correct_decisions, avg_ev_loss
       - last_practiced TIMESTAMPTZ
       - UNIQUE(user_id, spot_id), indexes on (user_id, spot_id), (user_id, hero_position), (user_id, last_practiced)

    **Critical:** Enable RLS on EVERY table immediately after creation: `ALTER TABLE {name} ENABLE ROW LEVEL SECURITY;`

    **Critical:** Enable replica identity FULL on training_sessions for Realtime: `ALTER TABLE training_sessions REPLICA IDENTITY FULL;`
  </action>

    - All FK references point to auth.users(id) or training_sessions(id)
    - GIN index exists for spots.tags
  </verify>

  <action>
    1. Create `supabase/migrations/002_rls_policies.sql` with all RLS policies:

       **profiles:**
       - SELECT own profile (authenticated, WHERE (SELECT auth.uid()) = id)
       - UPDATE own profile (authenticated, USING + WITH CHECK on uid)
       - INSERT own profile (authenticated, WITH CHECK on uid) -- for trigger

       **spots:**
       - SELECT system spots (anyone, WHERE is_system = true)
       - SELECT own spots (authenticated, WHERE created_by = (SELECT auth.uid()))
       - SELECT shared spots (anyone, WHERE share_code IS NOT NULL)
       - INSERT own spots (authenticated, WITH CHECK created_by = uid AND is_system = false AND NOT is_anonymous)

       **training_sessions:**
       - ALL own sessions (authenticated, USING + WITH CHECK uid = user_id)

       **session_entries:**
       - ALL own entries (authenticated, via subquery on training_sessions.user_id)

       **daily_stats and spot_stats:**
       - ALL own stats (authenticated, USING + WITH CHECK uid = user_id)

       **Critical:** Use `(SELECT auth.uid())` everywhere (wrapped in SELECT for query planner caching -- 99.99% performance improvement per Supabase docs).

    2. Create `supabase/migrations/003_triggers_functions.sql`:
       - `handle_new_user()` function: SECURITY DEFINER, inserts into profiles on auth.users INSERT
       - display_name defaults to COALESCE(raw_user_meta_data->>'display_name', split_part(email, '@', 1))
       - `updated_at` auto-update function and triggers for profiles, spots, training_sessions, spot_stats

    3. Apply migrations to Supabase Cloud:
       - Run: `npx supabase db push` (pushes local migrations to remote)
       - If Supabase CLI needs linking first: `npx supabase link --project-ref <ref>` (ref from dashboard URL)

    4. Generate TypeScript types:
       - Run: `npx supabase gen types --lang=typescript --project-id <ref> > src/lib/supabase.types.ts`
       - Update `src/lib/supabase/types.ts` to re-export: `export type { Database } from '@/lib/supabase.types'`
       - Also export table row types as convenience aliases: `export type Profile = Database['public']['Tables']['profiles']['Row']` etc.

    5. Update the three client files in `src/lib/supabase/` to import the real Database type instead of placeholder.
  </action>

    - `src/lib/supabase.types.ts` contains generated types with Database interface
    - `src/lib/supabase/types.ts` exports Database and convenience types
    - `npm run build` passes with real types
  </verify>
