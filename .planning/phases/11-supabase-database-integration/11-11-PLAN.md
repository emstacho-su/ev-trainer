Write a Node.js script (run it inline with `node -e`) to transform the existing ev-demo-pack-v2.json:

For each spot in the pack:
1. Read the current `positions` array (e.g., ["UTG", "BB"]) and `stacksBb` (e.g., {"UTG": 20, "BB": 20})
2. Define the full 6-max seat order: ["UTG", "HJ", "CO", "BTN", "SB", "BB"]
3. Set `positions` to the full 6-max array: ["UTG", "HJ", "CO", "BTN", "SB", "BB"]
4. For `stacksBb`, keep the existing values for hero and villain positions. For newly added positions (the folded ones), set their stack to the same effectiveStackBb value as the existing players (they started with the same stack before folding).
5. The `history`, `heroToAct`, `potBb`, and `board` fields remain unchanged.
6. The `meta.heroPosition` and `meta.villainPosition` remain unchanged.

The key insight: in a preflop spot, the `history` array contains the actions that happened BEFORE hero's decision. The `positions` array tells the table which seats exist. The `spotToPlayers` function in PreflopTrainingSession.tsx uses `spot.positions` to render player seats, and determines folded status by parsing the history. Since the history doesn't include actions for the newly added folded positions, the `parseHistoryActions` function will naturally not find actions for them, and they'll show as inactive/folded (which is correct -- they folded before the tracked action history began).

IMPORTANT: The `validateSpotMeta` function in spotPack.ts checks that `meta.heroPosition` and `meta.villainPosition` are included in `spot.positions`. With the full 6 positions, this will still pass since hero and villain are always in the 6-max list.

IMPORTANT: The `validateSpotMeta` also checks that `effectiveStackBb` matches `Math.min(...Object.values(spot.stacksBb))`. Since all stacks will be set to the same value, this will still pass.

IMPORTANT: The `validateSpot` function checks that `stacksBb` keys match `positions` exactly -- no extra, no missing. So stacksBb must have entries for all 6 positions.

Write the transformation result back to `public/packs/ev-demo-pack-v2.json`.

Also apply the same transformation to `public/packs/ev-dev-pack-v1.json` if it exists and has the same 2-position format.
