  <action>
    1. Install packages: `npm install @supabase/supabase-js @supabase/ssr` and `npm install -D supabase`

    2. Create `src/lib/supabase/client.ts` -- Browser client:
       - Import `createBrowserClient` from `@supabase/ssr`
       - Export `createClient()` function that returns `createBrowserClient<Database>(url, anonKey)`
       - Use `process.env.NEXT_PUBLIC_SUPABASE_URL!` and `process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY!`

    3. Create `src/lib/supabase/server.ts` -- Server client:
       - Import `createServerClient` from `@supabase/ssr` and `cookies` from `next/headers`
       - Export async `createClient()` function
       - Use `getAll()` and `setAll()` cookie methods (NOT individual get/set/remove -- deprecated)
       - Wrap `setAll` in try/catch for Server Component compatibility (can't set cookies in Server Components)

    4. Create `src/lib/supabase/middleware.ts` -- Middleware client:
       - Export async `updateSession(request: NextRequest)` function
       - Create server client with request cookie access
       - Call `supabase.auth.getUser()` (NOT getSession -- security requirement)
       - Propagate cookies via both `request.cookies.set()` AND `supabaseResponse.cookies.set()`
       - Do NOT add redirect logic yet -- that comes in Plan 03

    5. Create `src/lib/supabase/types.ts`:
       - For now, export a placeholder `Database` type (will be generated after schema creation in Plan 02)
       - Comment: "Run `npm run gen:types` after schema migration to replace this placeholder"

    6. Create `.env.example` with NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY placeholders
       - Do NOT commit `.env.local` (should be in .gitignore already)

    7. Add `gen:types` script to package.json: `"gen:types": "npx supabase gen types --lang=typescript --project-id \"$PROJECT_REF\" > src/lib/supabase.types.ts"`

    Follow the exact patterns from 11-RESEARCH.md Pattern 1 (Three Supabase Clients).
  </action>
