Create `src/app/training/page.tsx` as a `'use client'` component that combines the session page's training loop with the config dialog overlay.

**State machine:**
```
Page load → CONFIGURING (dialog open, table visible but empty behind backdrop)
Start Training → TRAINING (dialog closes, session active)
Gear icon → CONFIGURING (dialog reopens with locked fields, session paused visually)
Session complete → redirect to /summary/[id]
```

**Core state:**
- `configOpen: boolean` -- controls TrainingConfigDialog visibility, starts `true`
- `sessionId: string | null` -- null until session started
- `seed: string | null` -- null until session started
- All session state from session/[id]/page.tsx: `session`, `currentSpot`, `uiState`, `selectedActionId`, `grade`, `handCount`, `correctCount`, `errorMessage`, `heroRange`, `villainRange`, `rangeModalOpen`
- `isStarting: boolean` -- loading state for session start
- `startError: string | null` -- error from session start

**URL params support:**
- Read `heroPosition` from `useSearchParams()` on mount. If present, pre-apply it to config via `updateConfig({ positions: [heroPosition] })` (same as TrainerLobby drill param handling).

**handleStartTraining:**
Adapt from TrainerLobby.handleStartTraining (lines 50-107):
1. Call `fetch('/api/session/start', { method: 'POST', ... })` with config values
2. On success: extract `sessionId` and `seed` from response, set them in state
3. Call `writeSessionRecord()` to persist initial session + spot
4. Set `currentSpot` from response `data.spot`
5. Set `session` from response `data.session`
6. Close config dialog: `setConfigOpen(false)`
7. Do NOT navigate -- stay on same page (this is the key difference from TrainerLobby)
8. If config.mode === 'FLOP', redirect to `/postflop-training?sessionId=...&seed=...` (postflop stays separate this phase)

**handleSubmitAction, handleNext:**
Copy directly from `src/app/session/[id]/page.tsx` (lines 448-556). These are the core training loop handlers. Key adaptations:
- `handleNext`: when `response.session.isComplete`, redirect to `/summary/[id]?seed=...&mode=...&reviewAvailable=...` (same as session page)
- Remove the `loadSession` bootstrap useEffect (session is started inline, not loaded from URL)
