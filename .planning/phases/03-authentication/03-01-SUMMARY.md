## Decisions Made

**Password Hashing Security:**
- Chose Argon2id (hybrid variant) for password hashing per OWASP recommendations
- Parameters: 64 MB memory cost, 3 time cost, 4 parallelism (balance between security and performance)
- Salts automatically generated by argon2 library (unique per password)

**JWT Token Strategy:**
- jose library selected for ESM-native and Edge Runtime compatibility
- 15-minute access token expiry (short-lived for security)
- HS256 algorithm with secret from environment variable
- Token payload: sub (userId), email, type ('access')

**Refresh Token Security:**
- 7-day expiry for refresh tokens (balance between UX and security)
- 32-byte cryptographically secure random tokens
- SHA-256 hashing before database storage (raw token never stored)
- Cascade delete with user for automatic cleanup

**Verification Token Expiry:**
- Email verification tokens: 24 hours (user convenience)
- Password reset tokens: 1 hour (shorter for security)
- All tokens hashed with SHA-256 before storage
