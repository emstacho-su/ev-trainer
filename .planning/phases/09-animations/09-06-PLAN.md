    **Approach:** Motion's `layoutId` prop causes an element to smoothly animate between its old and new DOM positions when it unmounts from one location and mounts in another. The dealer button moves between different absolute positions as `dealerPosition` changes.

    **Step A: PokerTable.tsx — Wrap dealer button in motion.div with layoutId**

    PokerTable.tsx already has `'use client'` and imports Motion from plan 09-05. If 09-05 was not yet completed, add `'use client'` and Motion import now.

    Find the dealer button section:
    ```tsx
    {/* Dealer button */}
    {dealerOffsets[dealerPosition] && (
      <div
        className="absolute z-20"
        style={{
          top: dealerOffsets[dealerPosition].top,
          left: dealerOffsets[dealerPosition].left,
          transform: 'translate(-50%, -50%)',
        }}
      >
        <DealerButton />
      </div>
    )}
    ```

    Replace the `<div>` wrapper with `<motion.div>` and add `layoutId="dealer-button"` and `transition`:

    ```tsx
    {dealerOffsets[dealerPosition] && (
      <motion.div
        key={dealerPosition}
        layoutId="dealer-button"
        className="absolute z-20"
        style={{
          top: dealerOffsets[dealerPosition].top,
          left: dealerOffsets[dealerPosition].left,
          transform: 'translate(-50%, -50%)',
        }}
        transition={{ duration: ANIM.DEALER_SLIDE, ease: EASE.OUT }}
      >
        <DealerButton />
      </motion.div>
    )}
    ```

    IMPORTANT: `layoutId` works by animating between DOM positions when the component re-renders with the same `layoutId` but different position values. The `key` prop should NOT change between dealer positions (remove `key` or keep it fixed) — if `key` changes, React unmounts/remounts and Motion sees it as a new component, not a position change.

    Actually: for `layoutId` to work correctly, the motion.div must persist in the DOM with the same layoutId as position changes via CSS. The `top`/`left` style values changing is what layoutId auto-animates. Remove `key={dealerPosition}` — that would break the layoutId animation by causing remount. Just use:

    ```tsx
    {dealerOffsets[dealerPosition] && (
      <motion.div
        layoutId="dealer-button"
        className="absolute z-20"
        style={{
          top: dealerOffsets[dealerPosition].top,
          left: dealerOffsets[dealerPosition].left,
          transform: 'translate(-50%, -50%)',
        }}
        transition={{ layout: { duration: ANIM.DEALER_SLIDE, ease: EASE.OUT } }}
      >
        <DealerButton />
      </motion.div>
    )}
    ```

    The `transition.layout` key specifically controls the layout animation duration.

    Make sure PokerTable.tsx has `'use client'` and imports `{ motion }` from `motion/react` and `{ ANIM, EASE }` from `@/lib/ui/animationTiming`.

    **Step B: DealerButton.tsx — No changes needed**

    DealerButton is a pure presentational component. The layoutId animation is applied to the wrapper div in PokerTable, not to DealerButton itself. Leave DealerButton.tsx unchanged.

    import { ANIM, EASE } from './animationTiming';

    /**
     * Reusable Motion animation props for modal overlay and content.
     *
     * Usage (Phase 7 RangeGridModal):
     *
     * ```tsx
     * import { AnimatePresence, motion } from 'motion/react';
     * import { modalOverlayProps, modalContentProps } from '@/lib/ui/modalTransition';
     *
     * <AnimatePresence>
     *   {isOpen && (
     *     <>
     *       <motion.div {...modalOverlayProps} className="fixed inset-0 bg-black/60" onClick={onClose} />
     *       <motion.div {...modalContentProps} className="modal-content">
     *         {children}
     *       </motion.div>
     *     </>
     *   )}
     * </AnimatePresence>
     * ```
     */

    /** Motion props for modal backdrop (fade in/out) */
    export const modalOverlayProps = {
      initial: { opacity: 0 },
      animate: { opacity: 1 },
      exit: { opacity: 0 },
      transition: { duration: ANIM.MODAL_OPEN, ease: EASE.OUT },
    } as const;

    /** Motion props for modal content panel (fade + scale from 95% to 100%) */
    export const modalContentProps = {
      initial: { opacity: 0, scale: 0.95 },
      animate: { opacity: 1, scale: 1 },
      exit: { opacity: 0, scale: 0.95 },
      transition: {
        duration: ANIM.MODAL_OPEN,
        ease: EASE.OUT,
        exit: { duration: ANIM.MODAL_CLOSE },
      },
    } as const;
    ```
