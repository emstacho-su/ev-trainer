    Update `src/components/poker/organisms/PokerTable.tsx` to animate chip bet containers using Motion.

    Add `'use client';` directive at the top (needed for motion components).

    Import `motion, AnimatePresence` from `motion/react`.
    Import `ANIM, EASE` from `@/lib/ui/animationTiming`.

    **Bet chip animation:**
    The bet chips are rendered in the "Bet chips on inner ring" section. Each chip lives in a `<div>` positioned absolutely on the table.

    Replace the bet chip `<div>` wrapper with `<motion.div>` using AnimatePresence for enter/exit:

    ```tsx
    import { motion, AnimatePresence } from 'motion/react';
    import { ANIM, EASE } from '@/lib/ui/animationTiming';

    // Inside the bet chips section:
    <AnimatePresence>
      {players.map((player) => {
        if (!player.bet || player.bet <= 0) return null;
        const pos = betPositions[player.position];
        if (!pos) return null;

        return (
          <motion.div
            key={`bet-${player.position}`}
            className="absolute z-20"
            style={{
              top: pos.top,
              left: pos.left,
              transform: 'translate(-50%, -50%)',
            }}
            initial={{ opacity: 0, scale: 0.3 }}
            animate={{ opacity: 1, scale: 1 }}
            exit={{ opacity: 0, scale: 0.3, transition: { duration: ANIM.CHIP_COLLECT, ease: EASE.OUT } }}
            transition={{ duration: ANIM.CHIP_SLIDE, ease: EASE.OUT }}
          >
            <Chip amount={player.bet} size="sm" />
          </motion.div>
        );
      })}
    </AnimatePresence>
    ```

    The `scale: 0.3` initial state simulates the chip appearing from the player's stack area (since we don't have exact pixel positions for stacks, scale-from-zero at the bet position is the appropriate approximation — visually reads as "chip slides out from seat area").

    The `exit` animation fires when a bet is removed (e.g., chips collected to pot at street end), giving a dissolve-out effect.

    NOTE: Adding `'use client';` at the top of PokerTable.tsx is required since motion components are client-only. This is fine — PokerTable is already rendered on the client side (it's used in PreflopTrainingSession which is a client component).

    Preserve all existing JSX structure — only replace the bet chip div wrappers with motion.div + AnimatePresence.
