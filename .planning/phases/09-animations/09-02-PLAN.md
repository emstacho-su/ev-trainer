  <name>Task 1: Create AnimatedCard component with deal entry + 3D flip</name>
  <files>src/components/poker/atoms/AnimatedCard.tsx</files>
  <action>
    Create `src/components/poker/atoms/AnimatedCard.tsx`.

    This component wraps `Card` and `CardBack` in a Motion-animated container that:
    1. **Deal entry**: Animates FROM `{ opacity: 0, scale: 0.3 }` (representing center of table) TO `{ opacity: 1, scale: 1 }`. Duration: `ANIM.CARD_DEAL` (0.15s). Ease: `EASE.OUT`.
    2. **3D flip** (hero cards only): After deal, rotates Y-axis from 180deg (showing CardBack) to 0deg (showing Card face). Uses CSS `perspective` + `transform-style: preserve-3d` + `backfaceVisibility: hidden` on inner faces. Duration: `ANIM.CARD_FLIP` (0.3s) ease-out.
    3. **Muck** (folded): When `isMucking` prop is true, animates to `{ opacity: 0, scale: 0.5, y: -20 }`. Duration: `ANIM.TABLE_RESET` (0.25s).

    Props interface:
    ```typescript
    interface AnimatedCardProps {
      rank: string;
      suit: 'h' | 'd' | 'c' | 's';
      size?: 'sm' | 'md' | 'lg';
      /** true = hero card, shows face-up after flip; false = villain card, stays face-down */
      faceUp?: boolean;
      /** true = card is being mucked (folded away) */
      isMucking?: boolean;
      /** Stagger delay in seconds so each card deals at a different time */
      dealDelay?: number;
      className?: string;
    }
    ```

    Implementation:
    - The outer `motion.div` handles the **deal entry** animation (opacity + scale from initial to visible).
    - For face-up cards, use an inner flip container: a `motion.div` with `style={{ transformStyle: 'preserve-3d' }}` animated from `rotateY(180)` → `rotateY(0)` after the deal completes (use `delay: ANIM.CARD_DEAL + (dealDelay ?? 0)`).
    - CardBack has `style={{ backfaceVisibility: 'hidden' }}` — visible when rotateY is 180.
    - Card (face) has `style={{ backfaceVisibility: 'hidden', transform: 'rotateY(180deg)' }}` — visible when rotateY is 0.
    - Villain cards (`faceUp = false`): only deal entry animation, no flip.
    - Muck animation: `motion.div` animate to `{ opacity: 0, scale: 0.5, y: -20 }` when `isMucking` is true.

    IMPORTANT 3D CSS requirements:
    - Parent of the flip div needs `style={{ perspective: '600px' }}`
    - Flip div needs `style={{ transformStyle: 'preserve-3d', position: 'relative' }}`
    - Both faces need `style={{ backfaceVisibility: 'hidden', position: 'absolute', top: 0, left: 0, width: '100%', height: '100%' }}`
    - Front face (CardBack) is the default visible side at rotateY(180deg) initial state
    - Back face (Card) has additional `style={{ transform: 'rotateY(180deg)' }}` and is revealed as parent rotates to 0

    Use `ANIM` and `EASE` from `@/lib/ui/animationTiming`.
    Import `motion` from `motion/react`.
    Import `Card` and `CardBack` from their respective files.
    Import `cn` from `@/lib/utils`.

    The component must be a 'use client' component.

    Size dimensions for the outer wrapper must match Card/CardBack dimensions:
    - sm: `w-10 h-14`
    - md: `w-14 h-20`
    - lg: `w-18 h-26`
