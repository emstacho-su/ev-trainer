  <name>Task 3: Implement CFR+ core functions</name>
  <files>src/lib/solver/cfr.ts</files>
  <action>
Implement CFR+ algorithm core components:

1. `regretMatching(regretSum: Float64Array): number[]`
   - Map regrets to positive (max(0, r))
   - Sum positive regrets
   - If sum <= 1e-9, return uniform distribution (critical for avoiding NaN)
   - Otherwise normalize: positiveRegret[i] / sum
   - Add assertion: result sums to ~1.0 (within 1e-6)

2. `updateRegrets(infoSet: InfoSet, actionValues: number[], nodeValue: number, opponentReach: number): void`
   - For each action i:
     - instantRegret = actionValues[i] - nodeValue
     - counterfactualRegret = instantRegret * opponentReach
     - infoSet.regretSum[i] += counterfactualRegret
     - infoSet.regretSum[i] = Math.max(0, infoSet.regretSum[i])  // CFR+ FLOOR AFTER ACCUMULATION
   - This is the critical CFR+ difference from vanilla CFR

3. `updateStrategySum(infoSet: InfoSet, strategy: number[], currentReach: number): void`
   - For each action i:
     - infoSet.strategySum[i] += currentReach * strategy[i]
   - Used for computing average strategy

4. `validateStrategy(strategy: number[]): void`
   - Assert all values >= 0
   - Assert all values <= 1
   - Assert sum within 1e-6 of 1.0
   - Throw descriptive error if invalid

5. Export default CFR config:
   ```typescript
   const DEFAULT_CFR_CONFIG: CFRConfig = {
     maxIterations: 1_000_000,
     targetExploitability: 0.1, // 0.1 mbb = 0.1% EV
     checkConvergenceEvery: 10_000,
   };
   ```

CRITICAL: The regret floor MUST happen AFTER accumulating counterfactual regret, not before. This is the CFR+ improvement over vanilla CFR and is essential for convergence.
