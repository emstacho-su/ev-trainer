Create bet size abstraction utilities:

1. `DEFAULT_BET_SIZES` constant:
   ```typescript
   const DEFAULT_BET_SIZES: Record<Street, number[]> = {
     PREFLOP: [1.0],  // Preflop uses raise multiples, not pot fractions
     FLOP: [0.33, 0.50, 0.75, 1.0],
     TURN: [0.33, 0.50, 0.75, 1.0],
     RIVER: [0.33, 0.50, 0.75, 1.0],
   };
   ```

2. `DEFAULT_RAISE_SIZES` constant:
   ```typescript
   const DEFAULT_RAISE_SIZES: Record<Street, number[]> = {
     PREFLOP: [2.2, 2.5, 3.0],  // Standard 2.2-3x opens/3bets
     FLOP: [2.2, 2.5, 3.0],
     TURN: [2.2, 2.5, 3.0],
     RIVER: [2.2, 2.5, 3.0],
   };
   ```

3. `getAbstractedBetSizes(config: BetSizeConfig, sizes?: number[]): number[]`
   - Takes pot size and stack size in BB
   - Returns array of bet amounts in BB
   - Filters out bets larger than effective stack
   - Adds all-in when stack <= 2 * pot (configurable threshold)
   - Deduplicates if all-in equals another size

4. `getAbstractedRaiseSizes(config: BetSizeConfig, sizes?: number[]): number[]`
   - Takes facing bet, pot size, and stack size in BB
   - Returns array of raise amounts in BB
   - Minimum raise = 2 * facingBet (per poker rules)
   - Filters out raises larger than effective stack
   - Adds all-in when stack <= 3 * facingBet

5. `roundToBb(amount: number): number`
   - Rounds to 0.5 BB precision (standard for solvers)
   - Avoids floating point accumulation errors

Key constraint: All amounts in BB as integers * 100 internally (like cents), convert for API.
  </action>
