Create reference solution storage and comparison utilities:

1. Reference JSON format (preflop.json):
   ```json
   {
     "version": "1.0",
     "solver": "PioSolver",
     "generated": "2026-02-04",
     "scenarios": {
       "preflop-rfi-btn": {
         "strategies": {
           "AA": { "FOLD": 0, "CALL": 0, "RAISE_2.5": 1.0 },
           "KK": { "FOLD": 0, "CALL": 0, "RAISE_2.5": 1.0 },
           "72o": { "FOLD": 1.0, "CALL": 0, "RAISE_2.5": 0 }
         },
         "ev": {
           "AA": 0.35,
           "KK": 0.28,
           "72o": -0.01
         }
       }
     }
   }
   ```

2. `loadPioReference(scenarioId: string): ReferenceSolution`
   - Load from JSON file
   - Validate structure
   - Return typed solution object

3. `ReferenceSolution` interface:
   ```typescript
   interface ReferenceSolution {
     scenarioId: string;
     strategies: Map<CanonicalHand, Map<string, number>>; // hand -> action -> frequency
     evs: Map<CanonicalHand, number>;  // hand -> EV in bb
   }
   ```

4. `compareSolutions(solver: PreflopSolution | PostflopSolution, reference: ReferenceSolution): ComparisonResult`
   - For each hand in reference:
     - Compare action frequencies (delta per action)
     - Compare EVs (absolute difference in bb)
   - Return detailed comparison results

5. `ComparisonResult` interface:
   ```typescript
   interface ComparisonResult {
     scenarioId: string;
     passed: boolean;           // All hands within tolerance
     maxEvDelta: number;        // Worst EV difference
     avgEvDelta: number;        // Average EV difference
     worstHand: CanonicalHand;  // Hand with largest delta
     handResults: Map<CanonicalHand, HandComparison>;
   }
   ```

6. `calculateEvDelta(solverEv: number, referenceEv: number): number`
   - Returns absolute difference in bb
   - Handles edge cases (NaN, Infinity)

Note: For initial implementation, reference JSON files can be populated with known PioSolver solutions. The structure supports future automated import from PioSolver exports.

<task type="auto">
  <name>Task 3: Implement validation suite runner</name>
  <files>src/lib/solver/benchmark/validation.ts</files>
  <action>
Create validation suite that runs all benchmarks and reports results:

1. `ValidationConfig` interface:
   ```typescript
   interface ValidationConfig {
     scenarios?: string[];      // Specific scenarios to run (default: all)
     tolerance: number;         // EV tolerance in bb (default: 0.001 = 0.1%)
     verbose: boolean;          // Print per-hand results
     stopOnFailure: boolean;    // Stop at first failure
   }
   ```

2. `ValidationResult` interface:
   ```typescript
   interface ValidationResult {
     scenarioId: string;
     passed: boolean;
     comparison: ComparisonResult;
     solverTimeMs: number;
     iterations: number;
     exploitability: number;
   }
   ```

3. `BenchmarkReport` interface:
   ```typescript
   interface BenchmarkReport {
     timestamp: string;
     totalScenarios: number;
     passed: number;
     failed: number;
     avgEvDelta: number;
     maxEvDelta: number;
     worstScenario: string;
     totalTimeMs: number;
     results: ValidationResult[];
   }
   ```

4. `runBenchmarkValidation(config?: ValidationConfig): Promise<BenchmarkReport>`
   - For each scenario in BENCHMARK_SCENARIOS:
     - Run solver (preflopSolver or postflopSolver based on type)
     - Load PioSolver reference
     - Compare solutions
     - Record result
   - Aggregate into BenchmarkReport
   - Return report

5. `formatBenchmarkReport(report: BenchmarkReport): string`
   - Pretty-print report for console output
   - Show pass/fail status per scenario
   - Highlight failures with worst hands

6. Add CLI entry point:
   ```typescript
   // Can be run via: npx ts-node src/lib/solver/benchmark/validation.ts
   if (require.main === module) {
     runBenchmarkValidation({ verbose: true }).then(report => {
       console.log(formatBenchmarkReport(report));
       process.exit(report.failed > 0 ? 1 : 0);
     });
   }
   ```
  </action>
