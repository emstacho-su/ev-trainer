  <name>Task 2: Implement suit isomorphism utilities</name>
  <files>src/lib/solver/abstraction/isomorphism.ts</files>
  <action>
Create suit isomorphism utilities based on Waugh 2013 algorithm:

1. `getRankValue(rank: Rank): number` - Returns 0-12 where A=0, K=1, ... 2=12
2. `areIsomorphic(hand1: Hand, hand2: Hand): boolean` - Returns true if hands are suit-isomorphic (same ranks, same suited/offsuit pattern)
3. `mapToCanonicalSuit(hand: Hand): Hand` - Normalizes suit assignment (first card gets 'h', second gets 'h' if suited or 'd' if offsuit)
4. `getSuitedStatus(hand: Hand): 'suited' | 'offsuit' | 'pair'` - Returns hand category

Key implementation details:
- Pair: both cards same rank, different suits by definition
- Suited: both cards same suit
- Offsuit: both cards different suits and different ranks
- Canonical form always has higher rank first

Add assertions to catch edge cases (same card twice, invalid suits).
  </action>

  <name>Task 3: Implement preflop canonicalization</name>
  <files>src/lib/solver/abstraction/cards.ts</files>
  <action>
Create preflop card abstraction:

1. `CANONICAL_HANDS: CanonicalHand[]` - Array of all 169 canonical hands in standard order:
   - Pairs first (AA, KK, QQ, ... 22) = 13
   - Then for each high rank, suited then offsuit with lower ranks
   - Total: 13 pairs + 78 suited + 78 offsuit = 169

2. `canonicalizePreflop(card1: Card, card2: Card): CanonicalHand`
   - Extract ranks and suits
   - Sort by rank (higher first using getRankValue)
   - Determine suited/offsuit/pair status
   - Return canonical string (e.g., "AKs", "AA", "72o")

3. `buildPreflopAbstraction(): Map<CanonicalHand, number>`
   - Returns map from canonical hand to bucket ID (0-168)
   - Used for array indexing in info set storage

4. `getAllCombosForCanonical(canonical: CanonicalHand): Hand[]`
   - Returns all actual card combinations for a canonical hand
   - Pairs: 6 combos (4 choose 2)
   - Suited: 4 combos (one per suit)
   - Offsuit: 12 combos (4 * 3)

Key constraint: Function must be pure and deterministic for reproducibility.
  </action>
