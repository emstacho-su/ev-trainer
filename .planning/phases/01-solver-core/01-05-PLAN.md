Create preflop equity calculation utilities:

**equity.ts:**
1. `calculatePreflopEquityMonteCarlo(hand1: Hand, hand2: Hand, iterations?: number): number`
   - Monte Carlo simulation of 5-card boards
   - Requires poker-evaluator-ts for hand ranking
   - Default 10,000 iterations for reasonable accuracy
   - Returns equity for hand1 (0.0 to 1.0)

2. `calculatePreflopEquityFromTable(canonical1: CanonicalHand, canonical2: CanonicalHand): number`
   - O(1) lookup from precomputed table
   - Used during CFR iterations for speed

3. `PREFLOP_EQUITY_TABLE: Map<string, number>` or `Float64Array`
   - 169 x 169 = 28,561 entries
   - Key format: `{hand1}:{hand2}` where hand1 < hand2 lexically
   - Symmetric: equity(A vs B) = 1 - equity(B vs A)

**precompute.ts:**
1. `generatePreflopEquityTable(iterations: number): Float64Array`
   - Generate full equity matrix
   - Store only upper triangle (symmetric)
   - Expected runtime: 5-30 minutes depending on iterations

2. `savePreflopEquityTable(table: Float64Array, path: string): void`
   - Save to binary file for fast loading

3. `loadPreflopEquityTable(path: string): Float64Array`
   - Load precomputed table from file
   - Validate checksum/version

4. `getEquityIndex(canonical1: CanonicalHand, canonical2: CanonicalHand): number`
   - Convert hand pair to array index
   - Handles symmetry (always canonical1 < canonical2)

Implement the core CFR+ tree traversal algorithm:

1. `PreflopSolverConfig` interface:
   ```typescript
   interface PreflopSolverConfig extends CFRConfig {
     treeConfig: PreflopTreeConfig;
     usePrecomputedEquity: boolean;
     equityTablePath?: string;
   }
   ```

2. `cfrTraverse(node: GameNode, reachProbs: ReachProbabilities, traversingPlayer: Player, store: InfoSetStore): number`
   - Recursive CFR+ traversal
   - Terminal nodes: return utility
   - Chance nodes: sample or enumerate outcomes
   - Decision nodes:
     - Get/create info set
     - Compute current strategy via regret matching
     - Recursively traverse children
     - Update regrets (only for traversing player)
     - Update strategy sums
     - Return expected value

3. `runCFRIteration(tree: GameNode, store: InfoSetStore, config: PreflopSolverConfig): void`
   - Run one full iteration for both players
   - Alternating updates: traverse for player 0, then player 1
   - (Or simultaneous updates if preferred)

4. `PreflopSolution` interface:
   ```typescript
   interface PreflopSolution {
     strategies: Map<string, number[]>; // infoSetId -> action frequencies
     result: CFRResult;
     infoSets: InfoSetStore;
   }
   ```

5. `solvePreflopScenario(config: PreflopSolverConfig): PreflopSolution`
   - Main entry point
   - Creates tree and info set store
   - Runs iterations until convergence or max iterations
   - Returns final average strategies

Key details:
- Use alternating player updates (standard for two-player)
- Track iteration count and time for progress reporting
- Call progress callback every N iterations
